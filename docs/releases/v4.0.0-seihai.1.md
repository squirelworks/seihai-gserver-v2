The first Seihai release of **GServer-v2**: the open-source Graal game server (`gs2emu`), forked from upstream GServer-v2 `beta4` (merged up to `25396a1`, 2026-11-09) and fixed so that the classic and modern Graal clients the Seihai project tests with can log in and play. It is the lab reference server that the Seihai Rust servers are checked against. Licence: GPL-3.0, as upstream. The original authors are credited in `README.md`.

## Upstream

This release carries upstream `beta4` up to `25396a1`, including its GS1 engine and movement fixes, NPC gmap sublevels, GS2 v4 bytecode, Z3-V1.02 levels, 1.x baddy drop rates, and fixes for a file loading crash, `.gupd`, UPnP and `getClientByteCode` crashes. The packet names are upstream gs2lib's, with the Seihai names kept as aliases.

## Fixes over upstream beta4

Every change is listed, with the files and the clients it fixes, in `CHANGES-SEIHAI.md`. The main ones:

**Logins and play**
- 1.33 to 1.39 are no longer kicked every 10 seconds (a packet-count frame was read as a new login).
- 2.05 no longer sticks on the loading screen, and 2.05 and 2.17 keep their packet stream in step from the first frame.
- 1.33 to 1.41: bow props are read correctly, and weapon uploads no longer kick the player.
- 3.04 and 3.153 are allowed in, and an unknown GS2 token no longer aborts the server.
- 5.12: the encryption steps now match the client in both directions.
- 5.12 and later (including 6.00): a weapon with no classes no longer crashes the server at login.
- New accounts get their hearts, and a 4.x account is never loaded invisible.
- Account flags are kept when an account is loaded; before, every flag was dropped on load and lost at the next save.

**Stability**
- More than 1024 sockets, or a mass disconnect, no longer crash the server, and a level full of walkers can no longer grow a send queue without bound.
- An idle level with items on the ground no longer ends the server when it unloads.
- An RC that bans a player who is online no longer hangs the server.
- RC folder rights are sent quoted, as RCs send them.
- RC Edit Account and Add Account keep load only, the admin level and the admin worlds, and Edit Attributes shows and keeps the account's flags.

**Resource packages**
- `.gpak` and encrypted `.gpake` packages are served to the clients that load them (`.gpake` to 4.20r8 and later, `.gpak` to 5.07 and later), with the `.gpake` key sent first from `config/gpakkeys.txt`. The new `gpaks` option lists packages to send at login. Build packages with `seihai-servertools gpak pack`.
- Packet ids that were `UNKNOWN` now carry their real names, in the code and in the logs.

**NPC-server**
- On a server-side world, level scripts with no `//#CLIENTSIDE` line run on the client again, as 1.x clients expect. New options let a world or level opt back in.

**Builds**
- It builds and starts on Linux, Windows (MSVC) and macOS (LLVM), and CI starts the default, classic and modern lab servers from the packaged build on every OS.

## Lab worlds included

- `default`: 2.00 to 3.153 (newmain generation), port 14802.
- `classic`: 1.33 to 1.41r1, port 14803.
- `npcdemo`: the built-in NPC-server, port 14804.
- `modern`: 4.20r8 to 6.037 and their resource packages, port 14805.

All four listen on `127.0.0.1` only, need no listserver and have UPnP off. See `bin/docs/lab-world.md`.

## Download

Pick the archive for your system: Linux x86_64 or Windows x86_64. Archives for macOS Intel (x86_64) and Apple Silicon (aarch64) are added to this release when GitHub's macOS build machines have room; if they are not here, build from the source archive. Unpack it and run `gs2emu --server default` (or `classic`, `modern` or `npcdemo`). On macOS, the first start may need right-click → Open, because the build is not signed. A file changed on disk while the server runs on macOS is only picked up after a restart.

The full source for this release is attached as the `-source` archive, as the GPL requires.
