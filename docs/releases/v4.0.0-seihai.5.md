The fifth Seihai release of **GServer-v2** (`gs2emu`), the lab reference server the Seihai Rust servers are checked against. It is a small follow-up to `v4.0.0-seihai.4` (2026-11-20). It ships the Apple Silicon macOS archive that seihai.4 lacked, makes Graal 3D servers show up in the server list as 3D, and keeps Latin-1 letters in GS1 text. Licence: GPL-3.0, as upstream. The original authors are credited in `README.md`.

Every change is listed in `CHANGES-SEIHAI.md`, with the files changed and the clients each change fixes.

## Fixes

- **Apple Silicon macOS build (#132).** The libtomcrypt port now builds for the triplet's CPU, so the cross-compiled `arm64-osx` `gs2emu` links again. seihai.4 had no Apple Silicon archive. A lab build of the port on the macOS 15 VM gave an arm64 `libtomcrypt.a`. If one macOS build fails, the release still attaches the other.
- **3D servers in the server list.** A `graal3d = true` server registers at HQ level 4, which the listserver tags `3 `, unless `onlystaff` hides it. Before this, Mac 3.153, which reads only the first tag, did not see a 3D server.
- **GS1 text keeps its Latin-1 letters.** The NPC-server's GS1 engine and the GS1-to-GS2 translator read scripts as Latin-1, not UTF-8. A sign's letter above 127 is encoded as `#K(233)`, not `#K(-23)`.

## Lab worlds and tests

- The lab worlds let in 3.0, 3.01, 4.02 to 4.03 and 6.1.1.3. None of these has been run against the worlds yet.
- A packet replay harness (#87) replays recorded sessions through the client, RC and NC packet handlers under the sanitizers. It has found nothing so far.

## Known issues

- `KNOWN-ISSUES.md` has the current list.
- macOS archives are built at release time when a macOS runner is free. If they are missing, build from the source archive.

## Lab worlds included

The same four worlds as before (`default`, `classic`, `npcdemo`, `modern`), all listening on loopback only. See `bin/docs/lab-world.md`; Graal 3D hosting is in `bin/docs/graal3d.md`.

## Download

Pick the archive for your system: Linux x86_64 or Windows x86_64, plus macOS Intel and Apple Silicon when they are attached. Unpack it and run `gs2emu --server default` (or `classic`, `modern` or `npcdemo`). On macOS, the first start may need right-click → Open, because the build is not signed.

The full source for this release is attached as the `-source` archive, as the GPL requires.
