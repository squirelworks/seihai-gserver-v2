The fourth Seihai release of **GServer-v2** (`gs2emu`), the lab reference server the Seihai Rust servers are checked against. It adds everything on the `seihai` branch since `v4.0.0-seihai.3` (2026-11-15): the upstream `beta4` merge up to `bc54973`, crash fixes found by the new sanitizer and fuzzing jobs, server-side NPC scripts on classic worlds, 1.x clients that draw balls and arrows, and a Graal 3D camera for 5.x. Licence: GPL-3.0, as upstream. The original authors are credited in `README.md`.

Every change is listed in `CHANGES-SEIHAI.md` (sections 2026-11-15 to 2026-11-20), with the files changed and the clients each change fixes.

## Upstream

- **Merged GServer-v2 `beta4` up to `bc54973`** (27 commits after `2de276b`, 2026-11-12 to 17). Positions now carry their unit in the type, so a local position can no longer be passed where a gmap-global one is expected, and NPC movement option 32 blocks in the direction the NPC moves.
- Earlier upstream `beta4` fixes, in upstream's form: a GS1 script that throws is dropped before `cleanup`, and account numbers written with a decimal point load.
- **gs2lib** now comes from seihai-gs2lib `efaabb3` (was `3deb1ea`): the gen-5 compressed cipher step rounds down for every client, which every 4.x build needs, and 6.1.1.3 (`GNP1905C`) gets a version id.

## Stability

- **Sanitizers and fuzzing (#87).** `-DSANITIZE=ON` builds with AddressSanitizer and UndefinedBehaviorSanitizer. A `sanitizers` workflow (Clang 18) runs the regression tests, a lab-world start and a scripted loopback session against `npcdemo` as 2.00, 2.31, 4.04r2 and 5.12. A libFuzzer target feeds the real client, RC and NC packet handlers.
- **Crashes and hangs fixed from those runs:** `PLI_THROWCARRIED` before the first level (null dereference); a level or file name with a byte from 0xF5 to 0xFF froze the main loop (also in stock `beta4`); a non-UTF-8 `WANTFILE` or `LEVELWARP` name sent a null source to `memcpy`; RC Server Options on a world with no `serveroptions.txt` (also in stock `beta4`).
- **Short and empty client packets (#103).** An empty `PLI_BADDYADD` no longer makes a type-224 baddy that sends 6.03r7 away; short packets are checked before they are read.
- **GR-V1.05 levels load in step again (#116).** A size check was inverted, so every multi-layer board started four bytes late. A malformed level no longer ends the server.
- **Packet-logging builds** no longer read past a 1.x login packet (#108). Release builds never compiled this code.

## New

- **Classic worlds run server-side NPC scripts (#106).** `created`, `timeout` and `playerenters` fire on a `generation = classic` world with the NPC-server, as on newmain. Level scripts with no `//#CLIENTSIDE` line stay client-side by default; `levelnpcscripts` and `serversidescriptlevels` choose per world or per level.
- **Graal 3D.** Protocol 19 (3.153, 4.04r2) gets a Sky and a walking Player control object (#105), and every 4.20r6/5.x client (protocol 21/24) gets a Camera facing the spawn point, so the 5.12 3D view is no longer black.
- **Server options (#96, #97):** `aptime5`, `npcrights`, `startap`, ghost mode (`ghostmodeenabled`, `ghostmodefornotstaff`), and tracked `speedhacktolerance`, `scriptstyle`, `defaultlanguage` and `translatedlanguages`.
- `KNOWN-ISSUES.md` lists the open bugs for outside contributors, and `VERSIONING.md` explains the `-seihai.N` numbering.

## Fixes

- **1.x draws balls and arrows (#106).** 1.20 to 1.41r1 get `PLO_ARROWADD` (19) without the player id, and a bare `shootball` in an event with no player shoots one ball at each player in the level. Server-side `shootball` is a Seihai extension: the official NPC-server never had it.
- **2.x clients on classic worlds (#107).** Prop 10 is read in the form of the client that sent it, so a walking 2.22 is no longer kicked; stock sword and shield `.gif` names go to 2.x as `.png`.
- **GS1 on the NPC-server:** `triggeraction` params (#112), `setcharprop` text, and GS1 weapons reach 5.08 to 5.12 as bytecode. GS2 client scripts with string literals compile (#110, #113).
- **Warps.** Local and global positions are no longer mixed up on player and NPC warps; a gmap warp to a client before 3.0 re-sends the `.gmap`; a server warp whose name starts with `3 ` no longer drops 5.12 (#114).
- **Script packets** follow the client: 193/132/133 through 5.12, 197/140 from 5.24 and 6.00 beta 1.
- The npcdemo world lets 2.00 to 5.12 in on its newmain line (#115).

## Checked with real clients

A loopback lab run on 2026-11-20 at `2b2c489` with an AddressSanitizer build: 1.39 on `classic`, 2.31 on `npcdemo` and Linux 6.03r7 on `modern` each logged in, loaded the level, walked, warped and got answers from a server-side NPC; 1.39 drew the server's `shootball`. Chat on the headless 6.03r7 could not be driven, so it was not checked. The one crash found (the packet-logging login dump above) is fixed in this release.

## Known gaps

- Real 3.151 and 3.153 still crash on their first 3D frame; 4.20r8 is protocol 24 and not served.
- `KNOWN-ISSUES.md` has the current list.
- macOS archives are built at release time when a macOS runner is free. If they are missing, build from the source archive.

## Lab worlds included

The same four worlds as before (`default`, `classic`, `npcdemo`, `modern`), all listening on loopback only. See `bin/docs/lab-world.md`; Graal 3D hosting is in `bin/docs/graal3d.md`.

## Download

Pick the archive for your system: Linux x86_64 or Windows x86_64, plus macOS Intel and Apple Silicon when they are attached. Unpack it and run `gs2emu --server default` (or `classic`, `modern` or `npcdemo`). On macOS, the first start may need right-click → Open, because the build is not signed.

The full source for this release is attached as the `-source` archive, as the GPL requires.
